# Vazifa Bot

A simple Telegram bot for managing student assignments and deadlines.

## Features

- Add assignments
- Set task priority
- Set deadlines
- View incomplete, completed, or all tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed

## Tech Stack

- Python
- python-telegram-bot
- SQLite
- python-dotenv

## Project Purpose

This project was created as a personal learning project to gain practical experience in backend development, databases, Telegram Bot API, Git/GitHub, and product development.

## Security

Bot credentials are stored in a `.env` file and are not included in the repository.

## Note

AI tools were used as a coding assistant during development.
